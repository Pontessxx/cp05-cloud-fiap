CP05 Cloud

Site servido por Nginx em container Docker, protegido por um pipeline de segurança no GitHub Actions.

As três barreiras do pipeline

Gitleaks

Varre o repositório em busca de segredos (tokens, chaves, senhas) e barra o commit antes que o vazamento aconteça.

Segredos

Semgrep

Análise estática do código (SAST). Aponta padrões vulneráveis, como o uso perigoso de eval.

Código

Trivy

Escaneia a imagem Docker em busca de vulnerabilidades conhecidas (CVEs) no sistema base e nas dependências.

Imagem 
push / pull_request  →  gitleaks  →  semgrep  →  trivy  →  imagem confiável
